# مشغل الوسائط (MediaPlayer) 🎵🎬

> مشغل وسائط متطور للفيديو والموسيقى على أندرويد، يعمل دون اتصال بالإنترنت. كان اسمه سابقاً VibePlayer، ثم أُعيدت تسميته إلى «مشغل الوسائط» (NabdhMedia).

## ما هو التطبيق؟

«مشغل الوسائط» تطبيق أندرويد لتشغيل ملفات الفيديو والصوت الموجودة على الهاتف وروابط البث المباشر، مع تشغيل صوتي مستمر في الخلفية. بُني بلغة Kotlin وواجهات Jetpack Compose ومكتبة Android Media3 ExoPlayer، ويُبنى تلقائياً عبر GitHub Actions.

## ماذا يفعل؟ وأهم الميزات

- **مشغل فيديوهات متطور:** دعم صيغ MP4 وHLS ‏(m3u8)‏ وملفات الفيديو المحلية، مع عناصر تحكم نيون ذكية وإخفاء تلقائي، وتقديم أو تأخير 10 ثوانٍ، وتغيير السرعة (0.5x – 2.0x)، والتدوير للشاشة الكاملة، وتغيير نسبة العرض (Fit / Zoom / Fill).
- **مشغل صوتيات في الخلفية:** تشغيل مستمر في الخلفية عبر `MediaSessionService`، مع إشعارات التحكم في شريط النظام وشاشة القفل، ومشغل مصغّر دائم مع مؤثر موجات صوتية حي وشريط تقدم.
- **مشغل كامل الشاشة:** أسطوانة ألبوم فينيل دوارة، ومؤقت نوم تلقائي (Sleep Timer)، ووضعا التكرار والعشوائي.
- **نقاط استئناف مستقلة لكل قائمة تشغيل:** حفظ تلقائي لمكان التوقف (المقطع والدقيقة بدقة) لكل قائمة بشكل منفصل، وزر «استئناف» بارز على بطاقة كل قائمة للعودة إلى اللحظة نفسها بضغطة واحدة.
- **استيراد من الهاتف:** استيراد مجلد كامل بنقرة واحدة لإنشاء قائمة تشغيل مخصصة فوراً، وتحديد عدة ملفات دفعة واحدة، وتشغيل روابط البث المباشر المخصصة من الإنترنت.
- **يعمل دون اتصال:** تشغيل الملفات المحلية دون الحاجة إلى الإنترنت.

## كيفية الاستخدام

1. ثبّت التطبيق وامنحه إذن الوصول إلى ملفات الوسائط على الهاتف.
2. استورد مجلداً كاملاً أو حدّد عدة ملفات لإنشاء قائمة تشغيل.
3. شغّل فيديو أو مقطعاً صوتياً؛ ويمكنك إغلاق التطبيق وسيستمر الصوت في الخلفية، مع التحكم من الإشعارات أو شاشة القفل.
4. لاستئناف قائمة سابقة، اضغط زر «استئناف» على بطاقتها للعودة إلى مكان التوقف نفسه.

## التقنيات المستخدمة

- **اللغة والواجهة:** Kotlin وJetpack Compose
- **التشغيل:** Android Media3 ExoPlayer و`MediaSessionService`
- **البناء:** Gradle (باستخدام Kotlin DSL)
- **البناء التلقائي:** GitHub Actions

## التثبيت

### تحميل ملف APK الجاهز

1. توجه إلى تبويب **Actions** في هذا المستودع.
2. اختر آخر عملية بناء مكتملة (Build & Package APK).
3. حمّل ملف APK من قسم **Artifacts** باسم `VibePlayer-Debug-APK`، ثم ثبّته على جهاز أندرويد.

ويمكن أيضاً تشغيل البناء يدوياً في أي وقت عبر النقر على **Run workflow** داخل تبويب Actions.

### البناء المحلي

```bash
git clone https://github.com/Ali-awwww/-AW.git
cd -AW
chmod +x gradlew
./gradlew assembleDebug
```

ملف APK الناتج سيكون في:

```
app/build/outputs/apk/debug/app-debug.apk
```
